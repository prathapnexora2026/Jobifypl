# Role picker photos

The "Choose your role" screen (app.html) uses two photos here:

- `candidate.jpg` — the person for **"I want a job"** (the smiling man photo)
- `recruiter.jpg` — the person for **"I want to hire"** (the woman at the laptop photo)

Save the two images with EXACTLY these names in this folder. They're shown as
98×98 rounded squares (cropped to fill), so any size works — square-ish looks
best. Until they're added, the cards fall back to a simple icon automatically.
